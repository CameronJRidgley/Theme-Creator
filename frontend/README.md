# Theme Creator Frontend

React frontend for the Theme Creator application built with Vite.

## Setup

1. Install dependencies:
```bash
npm install
```

## Running the Development Server

```bash
npm run dev
```

The app will be available at `http://localhost:3000`

## Build for Production

```bash
npm run build
```

## Features

- Modern React with Hooks
- Vite for fast development
- API integration with FastAPI backend
- Responsive design

## API Integration

The frontend connects to the FastAPI backend running on `http://localhost:8000`. Make sure the backend is running before starting the frontend.
